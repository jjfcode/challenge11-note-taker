# challenge11-note-taker

## Description

This repository contains a simple Notes API built with Node.js and Express. The API allows users to create, read, and delete notes stored in a JSON file. Each note is assigned a unique identifier for easy management.

## Features

- GET /notes: Retrieve all notes.

- POST /notes: Add a new note with a title and text.

- DELETE /notes/:id: Remove a note by its unique ID.
